# nope-call

![nope-call](branding/github/logo-128.png)

Блокировка входящих звонков по правилам — Android, задел под iOS.

Правила по номеру (точное совпадение, начало, окончание, регулярное выражение) и по операторской
подписи звонящего. Журнал звонков хранится локально, из него можно создать правило в один тап.

Всё работает офлайн: при проверке звонка приложение не обращается к сети, номера и журнал никуда
не передаются. Блокирует только при уверенности — если ни одно правило не совпало или что-то
отказало, звонок проходит.
